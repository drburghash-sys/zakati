# زكاتي | BAS

تطبيق عربي يعمل على الجوال (PWA) لحساب الزكاة بحسب نوع الأصل، وقيمة النصاب، والحول القمري الهجري.

## التشغيل والنشر

- الصفحة الرئيسية: `index.html`، والحسابات في `app.js`.
- GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
- رابط التشغيل بعد تفعيل Pages: https://drburghash-sys.github.io/zakati/
- يمكن استخدام «إضافة إلى الشاشة الرئيسية» في متصفح Chrome على Android.

## الأصناف

النقود، والذهب والفضة، والأسهم والصناديق والريت، والأراضي والعقارات، والمخزون التجاري، والذمم والديون، والصكوك، والأصول الرقمية، والمدخرات التقاعدية، والمحاصيل والمواشي والمقتنيات الشخصية.

## التنبيهات والحدود

- مدخلات الأسعار **يدوية**. لا تتوافر أسعار لحظية أو دفع إلكتروني.
- بعض الحالات الفقهية محل خلاف وتُرفع للمراجعة، ولا يجوز تفسير النتيجة الرقمية وحدها على أنها فتوى.
- البيانات محفوظة محليًا داخل متصفح المستخدم؛ احفظ نسخة JSON احتياطية بانتظام.
- مواقيت الحول بحسب تقويم أم القرى الذي يقدمه متصفح الجهاز؛ راجع الاختلافات المحلية في الرؤية.
- معاملات بيع الأسهم والصناديق/زكاة شركات الاستثمار، وزكاة الحلي المستعمل، والتزام الديون تقتضي التفصيل.
